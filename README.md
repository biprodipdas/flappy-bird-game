  🐦 Flappy Bird Clone
A classic Flappy Bird game clone built from scratch using HTML5 Canvas, CSS3, and Vanilla JavaScript. This project focuses on smooth physics and retro-style aesthetics without using any external game engines or libraries.

🕹️ Live Demo
https://flappy-bird-game-x8at.vercel.app

✨ Features
Physics-Based Gameplay: Realistic gravity and jumping mechanics.

Procedural Generation: Pipes are generated randomly with varying gap positions.

Responsive Design: Fully playable on both desktop and mobile devices.

High Score Persistence: Saves your personal best score using local storage.

Visual Effects: Includes smooth animations, scrolling backgrounds, and particle bursts on collision.

🛠️ Tech Stack
Language: JavaScript (ES6+)

Rendering: HTML5 Canvas API

Styling: CSS3 (Custom properties and Flexbox)

Structure: HTML5
